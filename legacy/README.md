# Legacy Research Artifacts

This directory contains the original experiment scripts and result logs from the
AcousticScope research prototype.

The scripts were written for a specific lab setup with:

- a physical Amazon Echo device,
- local speaker and microphone routing,
- GPU-backed speech-to-text and text-to-speech models,
- third-party TTS/LLM APIs,
- local absolute paths from the original machine.

For GitHub review, use the cleaned package in `src/acousticscope/`. The legacy
files are preserved to show project provenance and the original experiment
workflow, but they are not the recommended entry point.
